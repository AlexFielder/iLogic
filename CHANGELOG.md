# Changelog

This file records the notable changes to this project, newest first.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Each entry goes under one of **New**, **Improved**, **Fixed** or **Breaking**. A **Breaking** entry says what users need to do to migrate. Internal-only changes, such as tests, CI, build tooling and refactors, get no entry.
